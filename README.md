# Ifedubem Ezike Portfolio

Personal portfolio of **Ifedubem Ezike (DubemtheDsgnr)**, Product Designer and Product Manager based in Lagos, Nigeria.

A story driven, animated single page site showcasing 5+ years of product work across Africa, Asia, the UAE and Europe, with selected products, measurable outcomes and a downloadable resume.

## Structure

* `index.html`: the whole site (HTML, CSS and vanilla JavaScript, no build step)
* `ifedubem.jpg`: portrait (photo by IjeWorks Photography)
* `logos/`, `icons/`, `flags/`: company logos, institution icons and country flags
* `resume.pdf`: downloadable resume
* `portfolio-summary.pdf`: three page portfolio summary

## Run locally

Open `index.html` in a browser, or serve the folder:

```bash
npx serve .
```

## Deploy

The site is static, so it deploys as is to GitHub Pages (Settings, Pages, deploy from the `main` branch root) or to Vercel and Netlify with no build command.
